# Android ADB GPS Spoofer v1.2.1

- Paste a coordinate pair into either Teleport field. Commas or whitespace separate latitude first, longitude second. Both fields fill together; press Teleport to apply the position.
- Add Device now shows the ten most frequently used IP/port combinations, retaining existing frequency/recency ordering.
- Selected devices stay selected through temporary disconnections. Selected offline devices remain visible in the device menu.
- Devices started together, or added to an existing route, share one route timeline and coordinate payload. Reconnected devices reinitialize mock GPS and join the current position instead of starting a separate route. Other devices keep moving even if one ADB command is slow.
- Pause stays paused. Explicit stops and mode switches cancel old route recovery, including devices that are offline. Already-issued route writes drain before replacement mode writes.
- Desktop and standalone Web use the same route-group and reconnect command logic. Route sessions remain in memory and are not restored after application/server restart.

## Packaging fix

Pin pnpm to 10.15.0, include the lockfile hook during the Docker build, and build/verify native SQLite dependencies before copying them into the runtime image. This resolves the v1.2.0 Docker publishing failure caused by an unpinned pnpm upgrade.

## Validation

Browser checks cover both paste fields, retained device selection and all ten IP shortcuts. Electron and standalone Web builds and all three TypeScript configurations passed. Desktop and mobile browser layouts were checked. No physical devices were connected during validation.
