# v1.2.4

This patch fixes a Windows startup failure in the v1.2.3 desktop package:

```
Error: Cannot find module 'ee-first'
```

The Windows pnpm layout allowed electron-builder to omit transitive runtime modules from `app.asar`. Packaging now uses pnpm's hoisted layout with the tested pnpm 10.15.0 toolchain for reproducible cross-platform dependency collection. The release workflow also computes the main process production dependency closure and fails if any required package is absent from the packaged archive, including the reported Express dependency.

Validation includes the existing test and typecheck suites, Electron/Web builds, and package checks for Windows, Linux and macOS archives. The Docker image uses the same dependency layout. Physical Android device behavior remains a separate hardware check.
